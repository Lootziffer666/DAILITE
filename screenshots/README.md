# DAILITE API Data Export

## Available Endpoints

### Killers
`GET /api/reference/killers` - 43+ killers with origin and chapter info

### Survivors  
`GET /api/reference/survivors` - 53+ survivors

### Maps
`GET /api/reference/maps` - 47 maps grouped by realm

### Perks
`GET /api/reference/perks` - 321 perks (Killer, Survivor, General)

## Data Source
All data verified from deadbydaylight.wiki.gg (2026-07-06 audit)
